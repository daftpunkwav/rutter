# CLAUDE.md

[AGENTS.md](AGENTS.md) is this repository's rule set.

This file carries no rules of its own. Do not add rules here: a rule
that lives only in an entry-point file is read by one tool and missed
by the others. Add it to `AGENTS.md` (and, for machine-local rules,
`AGENTS.local.md`), which every agent entry point links to.
