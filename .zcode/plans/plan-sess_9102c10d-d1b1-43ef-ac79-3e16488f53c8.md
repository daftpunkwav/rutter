# M0 实施计划:引擎落地、观察层完整、CLI 可用

按蓝图 §10 M0 口径执行(已确认:完整 M0 / CI 下载+缓存引擎 / 裁剪 v1 本次实现)。规格先行(§7.8 "spec is the contract"),每步一个 commit,全程通过既有门禁(fmt、clippy -D warnings、header/encoding gate)。

## Step 1 — docs/SNAPSHOT_SPEC.md(规格先行)
- 序列化 JSON 节点契约:role / name / value / ref / checked / disabled / rect / children;隐藏元素省略(honesty rule)。
- ref 铸造(v1):页面内持久计数器发 `e<N>`,同页快照间稳定,导航后失效 → ReferenceExpired。
- YAML 文本格式:沿用 core::snapshot 已有实现,含 `× N` 折叠标记。
- token 预算 v1(默认 ~20k 字符):深度预算上限(48)→ 视口外稠密子树折叠 → 相似兄弟折叠(≥8 同 role 无名兄弟)→ 安全硬上限(深 512/10 万节点);预算类裁剪置 truncated=true。
- `build(url, PageMeta{viewport, scroll}, tree)`。

## Step 2 — 引擎下载器(rutter-engine::download)
- manifest.rs:解析 Chrome for Testing 清单(fixture 离线单测);store.rs:缓存布局、zip 解压、版本 pin、离线复用;fetch.rs:超时(清单 30s/下载 10min)+ 有上限重试(rustls)。
- `ensure()`:显式可执行路径(env/flag)优先 → 缓存 → 网络。新增 `EngineError::DownloadFailed`。依赖 reqwest/zip/dirs/tokio。网络测试 #[ignore]。

## Step 3 — supervisor + launcher(rutter-engine)
- `EngineLauncher` trait(引擎注册点,§8.1);`RestartPolicy`(指数退避 + 滑窗熔断);心跳探测→死亡→按策略重启;熔断后调用方得 `EngineError::Terminated`,rutter 永不崩。M0 仅进程级重启,会话状态恢复属 M2。mock Engine 单测。

## Step 4 — crates/engine-cdp(新 crate)
- chromiumoxide 0.5.7(§12 已接受风险,封闭于 trait);launch/engine/context/page 四模块;错误折叠进 EngineError;#[ignore] 集成测试(本地 fixture 启动→导航→evaluate→截图)。members 增补。

## Step 5 — observe:序列化 JS + 裁剪 v1
- `assets/serializer.js`(include_str! 嵌入,含 shadow root,try/catch 永不抛,ASCII-only);经 `PageHandle::evaluate(observe::serializer_script())` 注入,observe 保持零引擎依赖。
- builder 按规格实现裁剪/折叠;insta golden + proptest(永不 panic、预算不变式)。

## Step 6 — CLI 接线
- config.rs(缓存根、可执行覆盖、超时、headed);注册 CDP launcher;`open.rs`(ensure→navigate→serialize→build→stdout,错误带 hint);`browse.rs`(supervisor+有头+Ctrl-C 优雅退出);serve 保持诚实 M1 错误。TOML 配置文件随 M2 引入。

## Step 7 — CI 与脚本
- quality 矩阵扩 ubuntu+windows;新增 integration job(cache 引擎目录,`cargo test -- --ignored`);MSRV job(1.85 check);`scripts/smoke_open.sh`(10 站点验收辅助,手动跑)。

## Step 8 — 文档
README 用法(open/browse、下载行为、flags/env)、crate 表补 engine-cdp;CHANGELOG 记录。

## 验证
